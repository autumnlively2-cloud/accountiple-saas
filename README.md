# Accountiple — Profit & Tax Tracking

## Setup (do exactly these steps, nothing else)

```
npm install
npm start
```

That's it. Do NOT run `npm audit fix --force` — it will break the install.

The audit warnings are from old test-only packages inside react-scripts and are harmless for running the app.

## Build for production (Vercel does this automatically)

```
npm run build
```
